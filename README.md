## 🎯 Game Rules

- Player 1 uses **X**
- Player 2 uses **O**
- Match 3 symbols in:
  - Row
  - Column
  - Diagonal

to win the game.

If all cells are filled and nobody wins, the game becomes a draw.

---

## 🧠 JavaScript Functions

### `putZeroOrCross(cell)`

- Places X or O
- Prevents selecting occupied cells

### `checkWinner()`

- Checks all winning conditions
- Displays winner message
- Detects draw

### `resetGame()`

- Clears board
- Resets game automatically
