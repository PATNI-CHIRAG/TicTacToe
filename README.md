Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe Game built using HTML, CSS, and JavaScript.
This project allows two players to play Tic Tac Toe in the browser with automatic winner detection and draw checking.

🚀 Features
Two-player gameplay (X and O)
Prevents selecting occupied cells
Automatic winner detection
Draw detection
Auto reset after game ends
Clean and colorful UI
Responsive layout

🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
